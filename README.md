# EventTrace

EventTrace is a minimalist iOS app for fast personal event tracking and long-term pattern analysis.

Originally created for tracking recurring health symptoms, EventTrace is designed as a flexible life event tracker that can also be used for:

- health and symptoms
- mood tracking
- fitness activities
- habits
- medication intake
- learning sessions
- sleep observations
- personal events

## Features

- Extremely fast event logging
- Categories and reusable preset items
- GitHub-style heatmap calendar
- Timeline and history view
- Basic statistics and trend analysis
- CSV export
- Offline-first architecture

## Philosophy

The core idea is simple:

> Logging an event should take only a few seconds.

EventTrace focuses on:
- simplicity
- speed
- clean native iOS experience
- long-term usability
- maintainable architecture

## Tech Stack

- SwiftUI
- SwiftData
- Charts
- Native Apple frameworks
